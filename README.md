# CalHub（カルハブ）

> Googleカレンダー完全リアルタイム同期 ＆ 4画面ビュー特化型 PWAカレンダーアプリ

---

## 🌟 特徴・コア機能

1. **4種類のカレンダー表示バリエーション（横スワイプ対応）**
   * **1ヶ月・縦型特化ビュー（メイン）**: 1日〜31日を年間最大「31日基準」で毎月均一な行幅（高さ）で固定表示。ピンチアウトで拡大してそのまま縦スクロール可能。
   * **1ヶ月・通常カレンダー**: 日曜始まり・土曜終わりの7列グリッド。
   * **1週間表示**: 曜日ピル ＆ 日別スケジュール。
   * **カレンダー並列比較ビュー**: 複数のカレンダーを左右に並べて比較。
2. **直感的な予定の表示優先順 ＆ 複数日矢印表示**
   * **表示順の最適化**: ①矢印が必要な複数日予定 ➔ ②単日の終日予定 ➔ ③時間指定の予定（開始時刻が早い順）の階層ソート。
   * 24時間未満の深夜跨ぎ予定（例: 23:00〜翌02:00）は1日の予定として開始日に自然に配置。
   * 初日のみタイトルを表示し、2日目以降は縦に伸びるSVG矢印で期間を表現。
   * 太さ（細・標準・太）× パターン（実線・破線・グラデーション）× 先端形状をリアルタイムに変更・プレビュー可能。
3. **文字色・背景色の自由カスタマイズ（任意指定）**
   * 既存の予定の色（終日は白、時間指定は黒）を崩さず維持したまま、任意で予定ごとに「文字色（白・黒・赤・青・緑・黄・紫・カスタム色）」や「背景色」をピンポイントで強調設定可能。
   * カテゴリー（カレンダー）単位での基本文字色・背景色の変更にも対応。
4. **日付タップ即時デイリー詳細ポップアップ**
   * どの表示モードからでも日付タップで即座に起動。
   * **メモ・場所内のURLリンク有効化（ワンタップ外部起動）**: コピペ不要でワンタップで直接ブラウザや対応アプリへジャンプ。
   * **24時間デジタル縦スクロール時間ピッカー**: アナログ時計を廃止し、時・分の2列ドラムロール。開始時間を変えると所要時間を保って終了時間も自動追従。
5. **長押しコピー＆連続ペースト**
   * 450ms長押しで予定をコピー。画面下部にスティッキー操作バーが常設され、別日をタップして連続作成が可能。
6. **通信最適化 ＆ オフライン完全対応**
   * 350msデバウンスと10分間のデータキャッシュにより、月めくり時の過剰なAPI通信を徹底カット。
   * オフライン時（電波なし）でもローカルDB（IndexedDB/localStorage）から高速・安全に閲覧・利用可能。
7. **全期間予定検索機能**
   * タイトル・メモ・場所を横断検索し、該当予定をタップするとその日付へジャンプ。
8. **誤作動・誤爆防止の安全設計（Android / iOS両対応）**
   * 1画面フィット時（倍率1.0x〜1.3x）はドラッグを禁止し、タップ操作に専念。
   * 2本指（ピンチ）の最優先処理（Safariのページ全体ズームを抑制）。
   * 水平フリックの明確な分離（横移動50px以上かつ縦移動の2倍以上）。
   * `user-select: none` によるiOS拡大鏡・テキスト選択メニューの抑制。

## 🛠 技術スタック

* **フロントエンド**: React 18, Vite, TypeScript, Tailwind CSS
* **ドラッグ＆ドロップ**: `@dnd-kit/core`
* **アイコン**: `lucide-react`
* **認証・API**: Google Identity Services (GIS) OAuth 2.0 ＋ Google Calendar API v3
* **PWA**: Android アダプティブアイコン（外周20%セーフゾーン確保）、iOS ホーム画面追加対応（Dynamic Island・セーフエリア対応）
* **ホスティング**: Cloudflare Pages（完全サーバーレス静的ホスティング）

## 🚀 ローカル起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

起動後、ブラウザで `http://localhost:5173` にアクセスします。
※Google Client ID未設定の状態でも、**モックデータとローカル永続化（localStorage）で全機能を即座に体験できます**。

## 🔑 Google Cloud Console の OAuth 設定手順

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスし、プロジェクトを作成（または選択）。
2. **「APIとサービス」 > 「ライブラリ」** から **Google Calendar API** を検索して「有効にする」。
3. **「APIとサービス」 > 「OAuth 同意画面」**:
   * User Type: 「外部」
   * アプリ名、ユーザーサポートメールを入力して保存。
   * スコープの追加: `.../auth/calendar` を追加。
   * テストユーザー: ご自身のGoogleアカウントを追加。
4. **「APIとサービス」 > 「認証情報」 > 「認証情報を作成」 > 「OAuth クライアント ID」**:
   * アプリケーションの種類: **「ウェブ アプリケーション」**
   * **承認済みの JavaScript 生成元**:
     * `http://localhost:5173` (ローカル開発用)
     * `https://<あなたのプロジェクト名>.pages.dev` (Cloudflare Pages 本番URL)
   * 作成完了後、表示された **クライアント ID** をコピーします。
5. プロジェクトルートに `.env` ファイルを作成し、以下を記述します:
   ```env
   VITE_GOOGLE_CLIENT_ID=コピーしたクライアントID.apps.googleusercontent.com
   ```

## ☁️ Cloudflare Pages へのデプロイ手順

1. GitHub に本リポジトリを push します。
2. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) にログインし、**「Workers & Pages」 > 「作成」 > 「Pages」 > 「Git に接続」** を選択。
3. リポジトリ `CalHub` を選択し、以下のビルド設定を入力します:
   * **フレームワーク プリセット**: `Vite`
   * **ビルド コマンド**: `npm run build`
   * **ビルド出力ディレクトリ**: `dist`
4. **「環境変数」** に以下を追加:
   * 変数名: `VITE_GOOGLE_CLIENT_ID`
   * 値: Google Cloud Console で取得したクライアント ID
5. **「保存してデプロイ」** をクリックします。数十秒で本番URL（`https://xxxx.pages.dev`）が発行されます！
